# EES-School-Website
A modern, responsive school website built with HTML, CSS, and JavaScript to showcase Edjeba Estate School’s mission, programs, and student life. This project features a sleek design, interactive navigation, and a vibrant gallery highlighting Nigerian students in science, culture, sports, and creative performances.
✨ Features
Fully responsive layout for desktop and mobile

Sticky navigation bar with smooth scrolling

Dynamic gallery with real Nigerian school scenes

Sections for Home, About, Programs, Gallery, and Contact

Clean, modern UI with accessible design principles

🛠️ Technologies
HTML5

CSS3 (Flexbox & Grid)

JavaScript (for interactivity and animations)

🌍 Purpose
To provide an engaging online presence for Edjeba Estate School, celebrating learning, culture, and community
